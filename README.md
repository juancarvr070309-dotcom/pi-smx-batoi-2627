# pi-smx-batoi-26-27
Este es le repositorio de ejemplo del proyecto intermodular de SMX del curso 26-27

# Treball Projecte Intermodular

Script i configuració bàsica per a desplegar un servidor d'infraestructura en una xarxa local d'empresa.

## Objectius

* Configurar el servidor principal per a la xarxa local.
* Assignar adreces IP fixes als equips de l'empresa.
* Automatitzar la instal·lació de serveis essencials.

## Dispositius de la xarxa

| Equip | IP | Sistema Operatiu |
| ----- | ----- | ----- |
| Servidor | 192.168.1.10 | Debian 12 |
| PC-01 | 192.168.1.50 | Windows 11 |
| PC-02 | 192.168.1.51 | Ubuntu Desktop |

## Instal·lació

Per a començar, actualitza els repositoris del sistema:

```bash
sudo apt update | sudo apt upgrade -y
```
